# DARKGRAM-per

Репозиторий для сборки Android-клиента.

## CI/CD (GitHub Actions)

Настроен автоматический билд APK.

### Как это работает

1. Залей исходный код Android-проекта в этот репозиторий (должен быть `gradlew`, `build.gradle` / `settings.gradle`, папка `app/` и т.д.).
2. При каждом push в ветку `main` (или вручную через Actions) будет запускаться сборка.
3. Готовые APK появятся во вкладке **Actions** → выбранный workflow → Artifacts.

### Ручной запуск

- Перейди во вкладку **Actions**
- Выбери workflow **Build Android APK**
- Нажми **Run workflow**

### Важно

Пока в репозитории нет реального Android-проекта (с Gradle), сборка просто сообщит об этом и завершится без ошибки.

После загрузки исходников CI начнёт собирать Debug и Release APK.
